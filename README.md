# Python-Projects
Python Projects from The Tech Academy
These are basic projects written in Python. They use various modules such as tkinter or sqlite3.

---

##Projects

-**Django University Project**
A CRUD university management system web application built with Django that allows administrators to manage student courses. The project demonstrates models, views, forms, database design, CRUD and templates.

-**Django Checkbook Project**
A CRUD web application built with Django that allows users to create multiple accounts, add deposits and withdrawals, record transactions, and view balances, history etc. The code was written with HTML and CSS for the user interface. This project demonstrates models, views, forms.


-**Nice or Mean Game**
Text based computer game where user chooses to be nice or mean. The user’s choice determines their fate, with nice gestures leading to winning the game, to bad gestures leading their their ultimate doom.  This game passes and returns information to and from functions, uses variables, and applies conditional logic to control game flow.

-**Check Files Gui**
This program that allows users to move files from one folder to another. All files that are moved are saved in a database. I used Tkinter to write a script that creates the GUI, acting as an interface for users to transfer files from one directory to another.
