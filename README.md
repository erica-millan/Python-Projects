# Python Projects

Python Projects from The Tech Academy  
These are basic projects written in Python. They use various modules such as `tkinter` and `sqlite3`.

---

## Projects

### Django University Project
A CRUD university management system web application built with Django that allows administrators to manage student courses.  
Concepts applied: models, views, forms, database design, CRUD operations, and templates.

---

### Django Checkbook Project
A CRUD web application built with Django that allows users to create multiple accounts, add deposits and withdrawals, record transactions, and view balances and history.  
The interface is styled with HTML and CSS.  
Concepts applied: models, views, and forms.

---

### Nice or Mean Game
A text-based computer game where the user chooses to be nice or mean.  
Nice gestures lead to winning the game; mean gestures lead to doom.  
Concepts applied: function input/output, variable use, and conditional logic.

---

### Check Files GUI
A program that allows users to move files from one folder to another.  
All moved files are saved in a database.  
The GUI is built with Tkinter to provide a simple interface for file transfers.
